## 1. Phase A 의 핵심 — 왜 "생성형 도구 기본값처럼" 보였나

취향의 문제가 아니라 **버그**였다.

```css
/* index.css — 레이어 밖에 있었다 */
@media screen { *, ::before, ::after { border-color: var(--color-gray-300) } }
```

CSS 캐스케이드 레이어는 **특정도보다 먼저** 평가된다. 레이어 밖의 `*` 가
`@layer components` 안의 `.card`(특정도 0,1,0)를 이긴다.
그래서 선언해 둔 테두리색이 **하나도 살아 있지 않았다.**

| 선언한 것 | 실제로 그려지던 것 | 고친 뒤 |
|---|---|---|
| `.card` gray-200 | gray-300 (1.56:1) | gray-400 **2.84:1** |
| `.panel` ink-100 | gray-300 (1.36:1) | ink-400 **3.24:1** |
| `.panel-accent` seal-200 | gray-300 (1.45:1) | seal-400 **2.60:1** |
| `.basis` ink-200 | gray-300 (1.44:1) | ink-400 **3.24:1** |
| `.btn-secondary` ink-300 | gray-300 (2.08:1) | ink-400 **3.52:1** |
| `border-2 border-ink-700` (강조 상자) | gray-300 | ink-700 그대로 |

즉 **주조색도 강조색도 구획선에 한 번도 나타나지 않고 있었다.**
`@layer base` 로 내리는 3줄이 이 커밋의 실질이다.

### A 의 나머지

- **반경 6px 하나로.** 4/6/8/full 이 섞여 있었다. Tailwind 의 `--radius-*` 단계를
  같은 값으로 묶어 JSX 를 손대지 않고 통일하고, 맨손 `rounded`(4px) 22곳만 고쳤다.
- **배경 gray-50 → gray-100.** 카드가 순백인데 배경이 #faf9f7 이면 둘의 대비가 **1.05:1** 이라
  "종이 위의 카드"가 아니라 한 장의 흰 화면으로 보였다.
- **제목 척도 고정** — h1 34 / h2 22 / h3·카드 18 / 본문 17.
  같은 층의 h2 가 16·17·18·20·24 **다섯 크기**로 흩어져 있었다.
  ★ `.print-sheet`·`.print-metrics` 안의 제목은 건드리지 않았다.
- **머리말 조작부 44px.** 실측 28~36px 이었다. 커진 만큼 세로 여백을 줄이고
  좁은 화면에서 저장 시각을 접어 첫 화면 노출을 지켰다.
- **법령 판본 카드**를 랜딩에서만 펼친다. 여섯 화면 바닥에 같은 블록이 반복돼
  화면마다 끝 인상이 같았다. ★ 접힌 상태에서도 주 법률의 판본과 시행일은 보인다.
- **고정폭 도입.** 고정폭 스택을 **먼저**, 한글 산세리프를 뒤에 둬 글리프 단위 대체로
  라틴 숫자만 고정폭이 되게 했다("제36조의2"의 36과 2만).
  조문 배지와 법령 판본에만 건다. 한글 문장에는 걸지 않는다.
  ★ **세리프는 채택하지 않았다** — 한글 시스템 세리프에 진짜 Bold 가 없다
  (macOS AppleMyungjo 는 Regular 단일, Windows 바탕은 합성 볼드).

## 2. Phase B

- **랜딩 상자 33 → 18** (첫 방문 실측). 그중 카드는 자가진단 1 + 권리 5 + 판본 1 + 접힘 3 = **11개**.
  나머지는 자가진단 안의 라벨 4, 버튼 1, 배지 1, 안내 1.

  종이 인상을 줬다. 서식 자신의 화면 테두리는 없앴다(카드 안의 카드로 보였다).
  ★ `.print-root` 여백 초기화 목록에 `border`·`box-shadow` 도 넣어 종이에 남지 않게 했다.
- **투어 모달.** 강조할 요소가 없는 첫 화면·마무리에서도 아래에 붙어 있어
  375×667 에서 그 윗변이 부제 한 줄을 **가로로 잘랐다.** 가릴 것이 없을 때는 가운데 카드로.
- **어두운 구간은 랜딩 히어로 하나.** 흰 글자 vs ink-900 = 16.7:1.
  어두운 바탕에서 주조색 버튼은 1.59:1 로 사라지므로 `.on-dark` 안에서만 명암을 뒤집는다.

  배경 인쇄를 끈 채로 랜딩을 인쇄하면 흰 바탕에 흰 글자가 되기 때문이다.
