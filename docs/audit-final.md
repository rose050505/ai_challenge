## ② 되돌리기 — ★ 여기서 하나 나왔다

| 경로 | 결과 |
|---|---|
| 샘플 A → 뒤로 → 샘플 B | B 로 정확히 바뀐다. A 의 서술이 남지 않는다 |
| 직접 쓴 서술 → 랜딩 | [이어서 하기] 로 이어진다. 저장됨 |
| 기록이 있을 때 투어 자동 열림 | **열리지 않는다** (설계 — 하던 일을 가로채지 않는다) |
| 기록이 있을 때 투어를 손으로 열기 | "덮어써집니다 … 먼저 [내보내기]로 저장해 주세요" 를 **먼저 말한다** |
| **기록이 있을 때 예시 카드 누르기** | **아무 말도 없이 진단을 통째로 덮어썼다** ← 고쳤다 |

### ★ 고친 것 — 예시 카드가 진행 중인 진단을 말없이 덮어썼다

실측 (배포본, `?sample=` 을 통해서가 아니라 랜딩에서 실제로 눌러서):

```
클릭 전 : eventId=limitReduced  업권=bank  서술="제가 직접 적은 사정입니다…"  이름=홍길동
클릭 후 : eventId=loanRejected  업권=""    서술="첫 직장에 입사한 지 8개월…"  이름=홍길동
되돌릴 수단: ["지우고 내 상황으로 시작하기"]   ← 되살리는 것이 아니라 더 지우는 단추다
```

- 덮어써지는 것: **진단 전체** — 겪은 일 · 상대 기관 · 업권 · 직접 쓴 서술
- 남는 것: 이름·연락처, 서식에 쓴 내용 (`setSection('diagnosis')` 만 하므로)
- **둘러보기는 시작 전에 이 사실을 말하는데(`TOUR_INTRO.overwriteWarning`) 예시 카드는 말하지 않았다.**
  랜딩은 바로 위에 [이어서 하기]를 띄워 기록이 있다는 것을 아는 상태였다.
- 심사위원은 기록이 없으니 만나지 않는다. **실제 사용자가 만나는 자리다** —
  자기 상황을 적어 두고, 궁금해서 예시를 눌러 보고, 적은 것을 잃는다.

→ 예시 고르기 패널에 **기록이 있을 때만** 뜨는 안내를 넣었다. 무엇이 바뀌고 무엇이 남는지
정확히 적고, 되돌리기가 없다는 사실과 [파일로 내보내기] 를 함께 말한다.
기록이 없으면 뜨지 않는다(실측 확인).

### ★ 고친 것 — 샘플을 고른 뒤에는 "우리가 만든 예시"라는 말이 사라졌다

- 고르기 **전** 화면에는 `RESPONSE_SAMPLES_NOTICE` 가 있다.
- 고른 **뒤** 화면은 "샘플 회신은 미리 준비된 해석 결과를 사용합니다." 한 줄만 남았다.
  **해석 결과가 준비된 것**이라고만 말하고, **회신문 자체가 지어낸 것**이라고는 말하지 않았다.
- 딥링크(`/response?sample=partial&run=1`)로 바로 들어오면 그 사실을 한 번도 못 본다.
  **둘러보기 정거장 2가 정확히 그 딥링크를 쓴다** — 즉 투어를 본 심사위원은
  지어낸 회신문의 해석 결과를 보면서 그것이 예시라는 말을 못 듣는다.
- 제출 문서가 §1-7-5 와 §4-2-8 에서 **"화면이 그렇게 밝힌다"고 주장하는 대목**이다.

→ `INTERPRET_FALLBACK_REASONS.sample` 한 상수를 늘렸다:
"샘플 회신은 미리 준비된 해석 결과를 사용합니다. **이 회신문 자체도 이 서비스가 만든
예시이며, 실제 금융회사가 보낸 문서가 아닙니다.**" 세 화면 모두에서 확인했다.
