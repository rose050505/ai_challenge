# 이 서비스가 실제로 하는 일

> **이 문서가 기준이다.** 앞으로 모든 문서와 대회 제출물(기획서·기능명세서)은 여기에 맞춘다.
> 반대가 아니다 — 코드가 바뀌면 여기를 먼저 고치고, 다른 문서를 따라 고친다.
>
> - 작성: 2026-08-31. 방법: **코드에서 출발했다.** 문서를 읽고 옮겨 적지 않았다.
>   `src/` · `api/` · `vercel.json` · `index.html` 을 읽고, 헤드리스 브라우저로 실제 동작을
>   재어 확인한 것만 적는다.
> - 확인 방법을 함께 적는다. 재보지 않은 것은 "확인하지 못한 것"에 넣는다.

## 1. 데이터 흐름

```
브라우저 ──(사용자 입력)──▶ React state ──(1.5초 멈추면)──▶ localStorage
                                │
                                ├─(/strategy 에서 [분석] 누를 때만)─▶ /api/analyze ─▶ Anthropic Claude
                                └─(/response 에서 [해석] 누를 때만)─▶ /api/interpret ─▶ Anthropic Claude
```

- **자동으로 나가는 것은 없다.** 두 요청 모두 사용자가 버튼을 눌러야 일어난다.
- 서버 함수는 받은 것을 Claude 로 넘기고 결과를 걸러 돌려줄 뿐, 어디에도 쓰지 않는다.
- 그 밖의 외부 통신은 **0건**이다. 웹폰트·분석도구·CDN·아이콘 모두 쓰지 않는다.
  (확인: 6개 화면을 순회하며 네트워크 요청 전수 수집 — 총 18건, 전부 자기 호스트)

## 2. 무엇이 서버로 전송되는가

**두 가지뿐이다.** 화면과 필드까지 특정한다.

| 화면 | 엔드포인트 | 나가는 필드 | 상한 | 언제 |
|---|---|---|---|---|
| `/strategy` | `POST /api/analyze` | `situation` — **`/diagnose` 마지막 단계의 자유 서술**(`#reason`)<br>`eventLabel` — 고른 사건 유형의 이름<br>`sectorLabel` — 고른 업권의 이름 | 서술 2,000자<br>이름 각 100자 | 사용자가 분석을 시작할 때 |
| `/response` | `POST /api/interpret` | `responseText` — **붙여넣은 회신 원문** | 12,000자 | 사용자가 [회신 해석하기]를 누를 때 |

- 상한은 `src/data/privacy.js` `TRANSMIT_LIMITS` 한 곳에서 정하고, 화면의 입력 제한과
  서버의 `slice()` 가 같은 값을 쓴다. 서버가 말없이 더 자르는 일은 없다.
- 받는 곳: **Anthropic (미국)**, 모델 `claude-sonnet-5`. **국외 이전에 해당한다.**
  화면이 입력란 바로 옆에서 이 사실을 말한다 (`AI_PROCESSING.short`).
- 요청은 브라우저 → 우리 서버 함수 → Anthropic 순서다. API 키는 서버 환경변수로만 읽는다.
  (확인: 배포 번들에 `sk-ant` · `ANTHROPIC_API_KEY` · `VITE_` 흔적 0건 — `tests/run-deployed.sh`)

### 전송되지 않는 것

- **성명 · 휴대폰 · 이메일** — 서식 화면에서 입력받지만 서버로 보내지 않는다.
- **서식에 적은 모든 내용** — 요청 항목, 희망 결과, 정정 사유, 제출할 정보 목록.
- **주민등록번호** — 애초에 입력받지 않는다. 입력란 자체가 없다.

## 3. 무엇이 저장되는가

### 저장되는 곳은 이 브라우저의 `localStorage` 뿐이다. 키는 다섯 개.

| 키 | 무엇 | 개인정보인가 |
|---|---|---|
| `wae:journey:state` | 진행 기록 전부 (아래 표) | **그렇다** |
| `wy-font-scale` | 화면 글자 크기 (3단) | 아니다 |
| `wy-plain` | 쉬운 말 보기 켬/끔 | 아니다 |
| `wy-print-scale` | 인쇄 글자 크기 (2단) | 아니다 |
| `wy-tour-v1` | 둘러보기를 봤다는 표시 | 아니다 |

> 키 이름(`wae:`, `wy-`)은 서비스명을 바꾸기 전 것이다. **바꾸지 않는다.**
> 바꾸면 이미 저장된 기록과 이미 내보낸 파일이 열리지 않는다.

### `wae:journey:state` 안에 있는 것

| 구역 | 담기는 것 | 원본이 어디서 왔나 |
|---|---|---|
| `diagnosis` | 고른 사건·상대방·업권, **자유 서술 원문**, 샘플 id | 사용자가 입력 |
| `strategy` | AI 후보 목록, 사용자가 고른 것, 출처(`ai`/`cached`/`fallback`) | AI 응답 + 사용자 선택 |
| `form.personal` | **성명 · 휴대폰 · 이메일** | 사용자가 입력 |
| `form.form1` / `form.form2` / `form.second` / `form.form2Extras` | 서식에 적은 모든 값 | 사용자가 입력 |
| `response.interpretation` | 설명받은 유형·빠진 유형, **기초정보 항목과 그 값**, 거절 사유 문장, 법정 제외 사유 문장 | **회신문에서 그대로 옮겨진 값** |
| `milestones` | 인쇄·제출 시각 | 사용자의 조작 |

### ★ 저장되지 않는 것 — 그리고 여기서 말을 조심해야 하는 곳

- **주민등록번호** — 어느 단계에도 없다. 저장 구조 자체에 자리가 없다. (`tests/tj.mjs` 가 검사한다)
- **붙여넣은 회신 원문 전체** — 저장하지 않는다. 해석이 끝나면 React 메모리에만 있고
  새로고침하면 사라진다.
  > ⚠️ **"회신 원문을 저장하지 않는다"로 줄여 말하지 마라.**
  > 저장되는 `interpretation.baseInfoItems[].내용` 은 **회신문에 적힌 값을 그대로 옮긴 것**이다
  > (예: `"2021년 3건 (총 연체일수 22일)"`). `api/interpret.js` 의 프롬프트가
  > "내용은 회신문에 적힌 값을 그대로 옮기십시오"라고 지시하고 있다.
  > 거절 사유 문장(`refusalReasonText`)·법정 제외 사유 문장(`provisoText`)도 마찬가지다.
  > **저장되지 않는 것은 "원문 전체"이지 "원문의 조각"이 아니다.**
  > 화면 문구는 `src/data/privacy.js` `RESPONSE_RETENTION` 한 곳에서만 관리한다.

### 저장 시점

- 입력이 **1.5초** 멈추면 저장한다(`IDLE_SAVE_MS = 1500`). 단계가 끝나는 시점에는 즉시 저장한다.
- 탭을 닫거나 숨기면(`pagehide` · `visibilitychange`) 대기 중이던 저장을 한 번 더 밀어 넣는다.
  (확인: 입력 200ms 뒤 전체 새로고침 — 값이 남았다. 200/600/1200/2000ms 네 경우 모두 남았다)
- 저장이 막힌 브라우저(시크릿 등)에서는 저장하지 않고, **화면이 그때는 그렇게 말한다**
  (`STORAGE_FACTS.blocked`). 기능은 죽지 않는다. (`tests/private.mjs` 9항목)

### 기기 간 연속성

- 계정이 없으므로 서버가 이어 주지 않는다. **파일 내보내기/불러오기**로만 옮긴다.
- 내보낸 파일은 `wae.journey` 표지를 단 JSON 이고, 위 `wae:journey:state` 의 내용이 그대로 들어간다.
  **파일에는 위 표의 개인정보가 전부 들어 있다.** 사용자가 직접 내려받아 직접 보관한다.

## 4. 무엇이 로깅되는가

- **이 서비스의 코드는 아무것도 기록하지 않는다.** `api/` 와 `src/` 에 `console.*` 호출이 **0건**이다.
  (확인: `grep -rn "console\." api/ src/` → 0건)
- 서버 함수는 오류가 나도 본문을 남기지 않는다. 오류 **종류**만 상태 코드로 돌려준다.
- 화면의 오류 경계(`ErrorBoundary`)는 **오류 객체를 상태에 담지 않는다.**
  담으면 사용자가 쓴 서술이나 회신에서 읽은 신용정보가 화면에 새어 나올 수 있다.
  `componentDidCatch` 도 의도적으로 비워 두었다.
- **다만 호스팅(Vercel)의 기본 접속 기록은 이 서비스가 정하지 않는다.**
  화면의 처리 내역 표가 이 사실을 그대로 적는다.

## 5. AI 가 하는 일과 하지 않는 일

### 하는 일 — 두 가지뿐

| | 하는 일 | 제약 |
|---|---|---|
| `/api/analyze` | 사용자 상황 서술 → **제출하면 유리할 정보 후보**로 번역 | 법정 범주(신용거래능력 판단정보) 안에서만. 최대 개수 고정 |
| `/api/interpret` | 회신문 → **법이 정한 세 유형 중 무엇이 담겼나** 분류, 기초정보 항목 추출 | 5분류 안에서만. 최대 20항목 |

- 모델 `claude-sonnet-5`, `output_config: { effort: 'low' }`,
  `max_tokens` 2048 / 4096, 서버 타임아웃 22초, 브라우저 타임아웃 25초.

### 하지 않는 일 — 코드에 상수로 박혀 있다

법조문 번호와 내용 · 거절 사유 목록 · 서식 항목 구조와 문구 · 처리 절차와 기한 · 제출처 안내.
전부 `src/data/law.js` 의 상수이고, 프롬프트에도 원문을 직접 넣어 **LLM 의 기억에 의존하지 않는다.**

### 서버가 AI 출력을 검사한다

- `applyGuards()` — 법정 범주 밖 제안을 버린다.
- `groundedReason()` — 선정이유의 **인용이 사용자 원문에 실제로 있는지** 대조한다.
  없으면 지어낸 인용이므로 그 이유를 버린다.
- `applyInterpretGuards()` — **세 유형을 모두 설명했다면 `refused` 는 참일 수 없다.**
  AI 가 참이라고 해도 코드가 뒤집고, 그 문장을 법정 제외(`provisoText`)로 옮긴다.

### AI 가 실패해도 화면은 간다

키가 없거나(503) 파싱에 실패하거나(502) 시간이 지나면(504),
`/strategy` 는 일반 목록으로, `/response` 는 수동 입력으로 넘어간다.
**화면은 그 결과가 AI 가 고른 것인지 일반 목록인지 캐시인지 구분해 말한다.**

## 7. 확인하지 못한 것

이 목록은 줄어들 때만 고친다. 확인하지 않은 것을 확인한 것처럼 옮겨 적지 않는다.

1. **두 서식의 정본(별지 서식 본문)을 대조하지 못했다.**
   재현본은 기관 공개본(서식 1 = BC카드, 서식 2 = HB저축은행) 기준이다.
   별지 서식 본문은 고시의 HWP 첨부로만 제공되는데 다운로드 식별자(flSeq)를 알아내지 못했다.
   - 확인한 것: 별지 제15호의2 의 개정 이력에 **제2026-37호(2026. 8. 13.)** 가 있다.
     즉 **정본은 2026-08-13 개정됐다.**
   - 확인하지 못한 것: 우리가 본 기관 공개본이 그 개정 **뒤**의 판본인지.
   - **화면이 이 사실을 그대로 적는다** (`FORM_ORIGINAL_UNVERIFIED`, 서식 화면 하단).
2. **별지 제15호의4(회신 서식)의 본문.** 같은 이유로 받지 못했다.
   "그런 법정 서식이 있다"까지만 말하고, 무엇을 담는지는 말하지 않는다.
   회신이 그 서식과 달라도 **위법이라고 단정하지 않는다** — 실무 관행을 확인하지 않았다.
3. **처리 기한.** 법·시행령·감독규정 세 층 원문을 모두 확인했고 **어디에도 없다.**
   그래서 카운트다운을 만들지 않고 경과일만 보여준다.
4. **Anthropic 의 보관 정책.** 우리가 정하지도 확인하지도 못한다.
   그래서 "저장하지 않습니다"를 그쪽까지 넓혀 적지 않고, 대신 **개인을 알아볼 수 있는 내용을
   애초에 쓰지 않도록** 입력란에서 안내한다.
5. **「은행법」 제2조제7호 · 「여신전문금융업법」 정의 조문 원문.** 용어집이 화면에서
   "직접 확인하지 않았습니다"라고 표시한다.
6. **실사용 검증.** 이 서비스로 만든 서류를 실제로 제출해 회신을 받아 본 사례가 없다.
   샘플 회신 2종은 **이 서비스가 작성한 예시**이고, 화면이 그렇게 밝힌다.
   몇 주에 걸친 실제 사용도 없다 — 시간 축은 기록의 시각을 과거로 심어 시험했다
   (`docs/audit-longitudinal.md`).

## 8. 이 문서를 쓸 때의 규칙

- **"저장하지 않는다"와 "전송하지 않는다"를 섞지 마라.** 다른 말이다.
  이 서비스가 지키는 것은 *서버에 저장하지 않는다* 이고, *전송은 일어난다*.
- **"원문 전체"와 "원문의 조각"을 섞지 마라.** §3 의 경고가 그것이다.
- 화면에 나가는 개인정보 문구는 **`src/data/privacy.js` 한 곳에서만** 만든다.
  화면마다 손으로 쓰면 동작이 바뀌어도 문구가 따라가지 못한다 —
  2026-08-30 감사에서 실제로 세 곳이 사실과 달랐다.
