# 인쇄 머리글·바닥글 여백 — 조사 기록

작성 2026-08-26. 계기: 실물 인쇄에서 "머리글 위와 꼬리글 아래 여백이 없다"는 보고.

## 가설

브라우저가 그리는 머리글·바닥글은 브라우저의 여백 영역에 그려지므로,
종이 끝에서 머리글까지의 간격은 CSS 로 제어할 수 없다.
우리 `@page margin` 은 **본문 위치만** 결정한다.

## 방법

A4 세로, 머리글·바닥글을 켠 상태로 실제 PDF 를 출력하고
`pdftotext -bbox` 로 각 글자의 좌표를 mm 로 환산해 측정했다.
본문 맨 위에는 `TOPMARKERAAA` 라는 표식 줄을 두어 본문 시작 위치를 읽었다.

- Firefox 153.0.1 — headless + 무음 인쇄 프리퍼런스(`print.always_print_silent`,
  `Mozilla Save to PDF`), 대화상자의 여백 설정은 `print.printer_*.print_margin_top/bottom` 으로 흉내
- Chrome (headless-shell 151) — CDP `Page.printToPDF` + `displayHeaderFooter: true`

## 측정값 (종이 위 끝에서의 거리, mm)

### Firefox

| 케이스 | CSS `@page` 세로여백 | 대화상자 여백값 | 머리글 글자 위 | 본문 시작 |
|---|---|---|---|---|
| A | 20mm | 0.5in (기본값) | **6.5** | 20.6 |
| B | 20mm | 0 (없음) | **6.5** | 20.6 |
| D | 20mm | 1.2in | **6.5** | 20.6 |
| C | 25mm | 0.5in | **6.5** | 25.6 |
| E (대조) | 선언 안 함 | 1.2in | **6.5** | 31.1 |
| F (대조) | 선언 안 함 | 0 | **6.5** | 7.0 |

### Chrome

| 케이스 | CSS `@page` 세로여백 | CDP 여백값 | 머리글 글자 위 | 본문 시작 | 바닥글 글자 아래 |
|---|---|---|---|---|---|
| c20 | 20mm | 20mm | **3.1** | 20.6 | 293.0 (종이 끝에서 4.0) |
| c25 | 25mm | 25mm | **3.1** | 25.4 | 293.0 |
| ccssonly | 20mm | 지정 안 함 | **3.1** | 20.6 | 293.0 |

## 결론

1. **머리글·바닥글 위치는 제어 불가.**
   여섯 개 Firefox 케이스와 세 개 Chrome 케이스 전부에서 머리글 위치가 동일했다
   (Firefox 6.5mm, Chrome 3.1mm). `@page` 여백을 20 → 25mm 로 올려도 머리글은
   그 자리에 그대로 있고 본문만 5mm 내려간다. **여백을 올리면 페이지 수만 늘어난다.**
   → 여백은 20mm 로 유지한다.

2. **Firefox 대화상자의 '여백' 설정은 우리 `@page` 여백을 덮어쓰지 않는다.**
   대화상자 값 0 / 0.5in / 1.2in 셋 다에서 본문 시작이 20.6mm 로 같았다.
   `@page` 여백을 선언하지 않은 대조군(E·F)에서만 대화상자 값이 그대로 반영됐다
   (1.2in → 31.1mm, 0 → 7.0mm). 즉 페이지가 CSS 로 여백을 선언하면 그쪽이 이긴다.
   → 사용자에게 여백을 바꾸라고 안내할 필요가 없다. **끌 것은 머리글·바닥글뿐이다.**

3. 여백 0 + 머리글 켬(케이스 F)에서는 머리글(6.5~11.6mm)과 본문(7.0mm~)이 겹쳤다.
   여백을 좁히는 방향은 위험하다는 근거이기도 하다.

>
> 지금 남은 것: 인쇄 버튼 옆 **한 줄** + 접어 둔 브라우저별 경로 + 쪽 번호 안내.
> "브라우저가 제어하므로 끌 수 없습니다"는 삭제했다 — 우리가 못 한 것을
> 변명하는 문단이었다. `wy-print-ack` 키도 함께 없앴다.
>
> 위의 실측(3.1mm / 6.5mm)은 그대로 유효하다. 여백으로는 못 옮긴다는 사실은 바뀌지 않았다.

## 재현

측정 스크립트는 임시 디렉터리에서 돌렸고 저장소에 남기지 않았다.
재현하려면 위 방법대로 `@page` 여백만 바꿔 두 번 출력한 뒤
`pdftotext -bbox` 로 머리글 글자의 `yMin` 을 비교하면 된다.
